# AnoCore

AnoCore is a private, in-development modular framework for Counter-Strike 2 servers built on CounterStrikeSharp.

The project is being developed as an independent successor architecture informed by the proven K4-Zenith design. K4-derived code remains subject to the GNU GPL v3.0 and is attributed accordingly.

Development follows an issue → branch → tests → implementation → documentation → pull request → CI → review → merge workflow.
